### 2. Sistema de Gestão de Rotas e Fretes
Sistema web para gestão de rotas e fretes com mapa interativo do Brasil e Colômbia.

**Características:**
- Interface web moderna e responsiva
- Mapa interativo mostrando representação em todos os estados brasileiros
- Cobertura internacional na Colômbia
- Formulário de contato completo
- API REST para integração

**Como executar:**

Opção 1 - Script de inicialização (recomendado):
```bash
# Linux/Mac
./iniciar_sistema.sh

# Windows
iniciar_sistema.bat
```

Opção 2 - Manual:
```bash
pip install -r requirements.txt
cd sistema_rotas_fretes
python app.py
```

Acesse: http://localhost:5000

Veja mais detalhes em [sistema_rotas_fretes/README.md](sistema_rotas_fretes/README.md)
